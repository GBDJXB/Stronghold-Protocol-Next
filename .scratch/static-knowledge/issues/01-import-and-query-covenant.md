**Blocked by:** None（can start immediately）。

**Status:** resolved

父规格：[卫戍协议静态知识库](../spec.md)。本编号属于 static-knowledge，与现有状态识别票号无关。

- [x] 从本地固定渲染材料自动提取灵巧盟约；使用原始材料，不以人工整理 JSON 冒充提取输入。保留完整可见效果文本，不执行公式。
- [x] 构建可重读知识快照并分配明确 snapshot_id；查询必须显式选择快照，返回规范名称、激活人数、效果文本、覆盖范围及具体来源位置。
