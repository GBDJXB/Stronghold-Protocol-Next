# 普通局内核心字段

只读 `analyze-archive` 入口输出独立的 `stage`、`remaining_time`、`funds`。每个字段有 status、可空 value、confidence、reason、raw_text、模型与字典 SHA256，共同绑定该分析的 frame_id、目录、原始 metadata 与请求时间。`remaining_time_unit` 固定 seconds；保存和重读均为 historical，不继承旧值。CLI 用法见 [历史状态记录](state-records.md)。

支持范围仅为本批 1920×1200 固定 HUD。分类仍作为适用性门控；unknown、局外与不支持画面不提取普通字段。休整阶段由独立的「休息一下」等稳定文本锚点识别；资金失败不影响阶段。休整时间为 unknown/null，原因 no_supported_visible_timer。用户标注说明本次个人模拟休整不限时，但程序没有独立模式认证，不据此输出默认 0 或声称判断所有模式均不限时。

战斗阶段依赖普通战斗文本锚点和未完成的敌人进度；进度已完成但无等待文本时阶段 unknown。底部完整「作战结束,等待队友完成作战」文本识别为 waiting，保留结束等待语义。阶段识别不依赖计时 OCR 成功；读取到电视数值也不能证明战斗仍在进行。资金仅来自已有黄色资金布局；白色 C 是部署费用，不冒充资金。

电视秒数使用本地 MAA PaddleCharOCR 神经识别。固定 TV 四角 TL(1720,63)、BL(1705,117)、BR(1805,145)、TR(1821,88) 双线性采样到 100×54，再用同一原生神经接口读数字。几何预处理不识别字符、不检索图片或样本 ID。接受 1–3 位数字且置信度至少 .95；不读序列、不从上一帧推测。开发探针中，直接矩形裁剪把 S026 的 38 高置信度 .9804 误读为 30；校正后读取 38。这证明模型置信度不是经过校准的正确率保证。

## 已运行检查及限制

public analyze/save/load seams 按垂直切片验证：休整阶段和未知时间、战斗 47 秒、结束等待 28 秒、模型来源及 schema2 roundtrip。前三项先观察失败后实现通过。另加人工黑掉 TV 的兼容合成存档，通过 public analyze 证明阶段仍 combat、时间 unknown/null，保存重读保留独立有效性；人工移除等待文字后完成进度保持阶段 unknown。这些变换不修改原图，也不作为真实识别准确率。

原生 C++ 开发检查 S020–S033 的十四个电视读数均与开发标注一致：47、45、44、42、41、39、38、37、35、34、32、31、29、28；S020–S032 阶段 combat，S033 waiting。S015/S017 阶段 rest，资金 4/0；S019 开始动画仍分类 unknown，所有字段未知。其余过渡与覆盖层由类别门控处理。

这是一局固定布局的开发调参与回归结果，不能当独立验收。未读取预留图或独立评估结果。仍缺独立战斗组、不同地图/模式/分辨率、真实不可读计时器与布局变化；不宣称跨分辨率、开放画面或全模式识别可靠性。真实游戏测试由用户决定后交独立测试对话。

处理开销为固定 ROI OCR 与 5400 像素几何采样；预处理时间/额外空间均 O(100×54)，一般化为 O(output pixels)。PNG 读入和模型推理的成本仍由图像大小与外部模型决定。

冻结后的预留评估：S055 休整阶段正确，资金网络虽读到 4，但布局守卫拒识，最终为 unknown；不能记为独立资金识别成功。独立战斗仍缺。完整结果见 [本轮验证](state-recognition-validation.md)。
